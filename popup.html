Settings
In-page sync notifications (toasts)

Shows a small message on Letterboxd when a sync starts and when it finishes or fails. If unsure, keep this on so you know each rating reached IMDb.

Switch to IMDb page after rating

Opens the film's IMDb page after each successful sync so you can see the new rating there. Off keeps you on Letterboxd.

Backup sync method

If unsure, keep this on for more reliable syncing. Off skips the backup entirely if the fast method fails.

TMDb lookup

Optional. Only needed for the few films Letterboxd doesn't link to IMDb — turn it on and add a free TMDb key so RateSync can look up their IMDb page.

TMDb Access Token
  1. Create a free account at themoviedb.org if you don't have one, then log in
  2. Go to themoviedb.org/settings/api
  3. Click Request an API Key → select Personal Use → fill in the form
  4. Copy either credential — the API Read Access Token (v4 auth) or the 32-character API Key (v3) — and paste it above. Both work.

🔒 Your key is stored locally and only sent to TMDb to look up film IDs.

All settings and sync history (up to 100) are stored locally and will be deleted if you uninstall the extension. This does not affect ratings on IMDb.
