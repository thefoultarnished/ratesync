2.0.0
Sep 27, 2026

A faster, quieter sync path, visible on-page feedback for every rating, and support for Letterboxd's current star-rating widget.

Fixed A change on IMDb's side started rejecting sync requests with a 4XX error, silently failing every sync. RateSync now sends the header IMDb's own site sends, so submissions go through again.

Added

  • Ratings are now submitted to IMDb directly in the background first — no tab needed in the common case. The tab-based method still runs automatically as a fallback (can be turned off in Settings)
  • Support for Letterboxd's current film-page star widget, not just the classic rating form and the log/diary dialog
  • On-page toasts confirm each stage on Letterboxd itself — "IMDb sync initiated", then "IMDb rating synced" or the exact failure reason (can be turned off in Settings)
  • A failed sync is retried automatically once, 5 seconds later, before anything is reported as failed
  • Inline Retry button on any failed sync in the popup log
  • TMDb lookup is now an explicit toggle, and accepts either a v4 Read Access Token or a 32-character v3 API key
  • Feedback link in the popup for reporting a broken sync

Improved

  • Popup UI polish: custom dropdown filter, system fonts throughout (no more bundled font files)
  • IMDb login indicator and general layout refinements
  • Shared, self-closing background tab for the fallback path — never lingers, never opens more than one at a time

Un-rating still isn't synced, and an IMDb rating is always fully overwritten by the latest Letterboxd rating — same as v1.5.0.

1.5.0
Apr 23, 2026

RateSync bridges Letterboxd and IMDb — the two most popular film platforms — so you never have to rate a film twice. The moment you rate a film on Letterboxd, RateSync automatically submits the same rating to your IMDb account in the background. No extra clicks, no switching tabs, no copy-pasting. Just rate once and you're done on both.

How it works

  1. You rate a film on Letterboxd (from the film page or the log/diary dialog)
  2. RateSync detects the rating in the background
  3. It looks up the film's IMDb ID via Letterboxd's film data
  4. It submits the equivalent rating to IMDb using your existing IMDb session
  5. The sync is logged in the extension popup — green for success, red for failure

Letterboxd's 5-star scale (0.5 increments) is converted to IMDb's 10-point scale automatically.

Features

  • Automatic — works silently in the background, no interaction needed
  • Sync log — view your recent syncs with film title, star rating, and timestamp
  • Stats bar — see total synced, success rate, and average rating at a glance
  • Filters — show only failed syncs or only unique films
  • Auto-open — optionally open the IMDb page after each sync
  • TMDb fallback — if Letterboxd doesn't carry a direct IMDb link, RateSync falls back to TMDb to resolve it (requires a free TMDb API token)
  • Login detection — the status pill in the header shows your IMDb connection state at a glance

Requirements

  • A Letterboxd account — free
  • An IMDb account — free, must be logged in on the same browser profile
  • A TMDb API Read Access Token — free, only needed for films where Letterboxd doesn't carry a direct IMDb link

Privacy & security

  • No accounts, no servers — RateSync runs entirely in your browser. No data is sent to any third-party server other than IMDb and TMDb (which is the entire point of the extension)
  • Your TMDb token is stored locally on your device in Chrome's extension storage and is only ever sent to TMDb to look up film IDs
  • Your IMDb session is used directly to submit ratings via IMDb's GraphQL API — the same session your browser already has. RateSync does not store or transmit your IMDb credentials anywhere
  • No analytics, no tracking, no ads
